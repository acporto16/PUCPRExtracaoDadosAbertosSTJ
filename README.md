# PUCP Extração de Dados Abertos STJ
### Íntegras de Decisões Terminativas e Acórdãos do Diário da Justiça

This project is designed to extract and process open data from the Brazilian Superior Tribunal de Justiça (STJ).

## Objective

The main goal of this project is to download, unzip, and process judicial data from the STJ for the year 2024. This includes handling metadata and the full text of judicial decisions and rulings.

## Python Version

This project uses Python 3.12.

## Dependencies

This project has no external dependencies.

## How to Use

1.  **Configure the constants:**
    *   Open the `const.py` file and set the `YEAR_DOWNLOAD` variable to the desired year.
2.  **Run the main script:**
    *   Execute the main Python script to start the data extraction and processing.
